# AssetManager 0.5.4

发布日期：2026-11-23
安装包：`AssetManager_0.5.4_x64-setup.exe`（NSIS / x64 / 7,160,640 字节）

本版把 0.4.28 之后的全部重构与新功能一次带上线：灵感板、启动体验、托盘、安装器、九国语言与一批交互细节。

---

## 灵感板

- **置顶开关**：板子窗口默认置顶，顶栏新增置顶按钮（默认开启），点掉即取消，切换立即作用于窗口。
- **竖排文字**：文字便签支持 Photoshop 式竖排（回车往左开新列），底部字体工具条新增「横排 / 竖排」切换，立即重排并落库；旧库读出仍为横排。
- **编辑态更干净**：编辑时去掉紫描边与深底，只留光标，并隐藏缩放手柄；点便签外即提交（空文本照旧删除）。
- **窗口去系统描边**：Win11 给无边框窗口自动补的 accent 描边已关掉（DWM 圆角/描边策略），拖动、缩放、聚焦后刷新。

## 启动与扫描

- **启动页**：启动先显示启动页（版式对齐 FontManager，文案走 i18n）。
- **启动扫描编排**：先扫当前素材库，扫完即显示主界面并关闭启动页；其余素材库（最多 2 个）在主界面显示后于后台继续扫，用既有 `scan://progress` 驱动底部进度条。
- 没有素材库 / 首次启动直接进主界面；开启「启动时最小化」时不弹启动页。
- 修掉启动扫描把「当前库」重复扫一遍的问题。

## 托盘

- **自绘右键菜单**：托盘右键在鼠标位置弹出独立小窗菜单（二级面板、失焦自动隐藏、DPI 正确），条目为 打开主界面 / 打开设置 / 切换素材库 ▸ / 切换主题 ▸ / 检查更新 / 退出软件，文案走九种语言。
- 左键仍直接打开主窗口；退出沿用既有 aux 窗口收尾逻辑。

## 安装 / 卸载界面（路线 C）

- 安装程序改为「路线 C」自绘 UI：主程序以 `--installer-ui` / `--uninstall-ui` 开窗绘制**四屏安装 + 三屏卸载**，NSIS 只当引擎。
- **中英双语**：跟随系统语言，系统语言为中文（zh*）时中文界面，其它一律英文；安装四屏与卸载三屏全覆盖，另留调试用语言覆盖参数。
- 左上品牌行显示的是**安装器自身版本**（升级安装时不再误显示已安装的旧版本）。
- 静默安装仍然可用；安装包与产品名统一为 `AssetManager`。

## 国际化

- 界面文案迁入仓库内 i18n，覆盖主界面、设置、灵感板与各浮层，共 **9 种语言**：简体中文、繁體中文、English、日本語、Русский、Deutsch、Español、Français、Português (BR)。
- 中文文案与迁移前逐字一致，其余语言补齐同批 key。

## 交互与视觉

- **空格 / 双击开合图片**：看图已开时，对同一张图再按空格或双击即关闭（原来是只开不合）。
- **F2 切换主界面**：可见且在前台时隐藏，被遮挡或已隐藏时显示并置前聚焦；已注册进现有快捷键体系。
- **关于页动效**：照 FontManager 的关于页动画与交互重做，配色/圆角/字体全部换成本项目设计令牌，信息保持完整。
- 前端补 memo 边界（侧栏/顶栏/快照/分组等回调稳定化），减少无关重渲。

## 验证

- `tsc --noEmit`、`vite build` 通过；`cargo test --release`（core）通过；`cargo check --release` 通过。
- 安装包装机核验：`FileVersion` / `ProductVersion` = 0.5.4，`runtime.log` 出现 `start v0.5.4`，托盘、热键、解码闸门均正常。
- 安装/卸载界面在中文与英文两种系统语言下各走一遍四屏/三屏。

## 已知限制

- 安装包未签名，首次运行可能出现 SmartScreen 提示。
- 默认 NSIS 流程之外的自绘界面只在 x64 上验证。
